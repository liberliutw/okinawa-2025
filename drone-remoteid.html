🚁 無人機 Remote ID 導入說明

日本飛行前必辦：機體登錄 + Remote ID

📡 什麼是 Remote ID？

依日本航空法，100g 以上的無人機在日本飛行，必須完成國土交通省 DIPS 2.0 機體登錄，並讓機體在飛行中持續廣播 Remote ID（登錄記號 JU 開頭、序號、位置等資訊），類似汽車的電子車牌。DJI 機種內建 Remote ID 硬體，但「登錄完 DIPS」不等於完成——還要透過 DJI Fly App 把 DIPS 的登錄資訊寫入（インポート）機體才算生效。

⚠️ 未登錄或未寫入 Remote ID 就飛行，最高可處 1 年以下有期徒刑或 50 萬日圓以下罰金。出發前務必完成全部步驟。

🔧 導入五步驟（DJI 機種）

  1. DIPS 2.0 機體登錄：登入 DIPS → 機体登録 → 填機體序號（SN）→ 繳登錄手數料 → 取得登錄記號 JU______
  2. DIPS 設定 Remote ID 型式：機体情報の確認/変更 → 「リモートID有無」選 「あり（内蔵型）」。此步驟沒做，DJI Fly 不會出現寫入選項！
  3. 韌體全部更新到最新：機體、遙控器、DJI Fly App 三者都要最新版，並確保網路連線與 GPS 收訊良好
  4. DJI Fly 寫入：連接機體 → 「安全」→「無人航空機システム リモートID」→ インポート → 跳轉國土交通省登入頁（SN 會自動帶入）→ 輸入 DIPS 帳號密碼 → 「同意して連携」→ 確認顯示「インポート済（已匯入）」
  5. 機身貼登錄記號：登錄記號需以高度 3mm 以上字體標示於機身（胴體等耐衝擊部位），不可貼在槳保護罩或電池上。可用標籤機列印貼紙
✅ 我們的 DIPS 登入 ID：RUL566031（密碼另存於密碼管理器，勿寫在此頁）

🗾 沖繩飛行前檢查清單

  • DIPS 飛行計畫通報（FISS）：每次飛行前於 DIPS 2.0 通報飛行計畫，並確認當地無臨時禁飛
  • 那霸機場周邊全面禁飛：那霸市區、機場進場面範圍內不可飛（Day 1/4 市區行程無飛行機會）
  • 美軍設施周邊禁飛：嘉手納、普天間等基地周邊，北部沿岸點起飛前先查 GSI 地圖確認
  • DID 人口集中地區：需國交省許可才可飛，未申請包括申請（包括許可）者避開
  • 私有地需地主同意：沖繩世界等園區需業者書面同意
  • 基本規則：日中飛行、目視範圍內、對人對物 30m 距離、150m 高度以下
💡 行程中的可飛點與注意事項，見景點頁各卡片的無人機標註（備瀨自然區域、南部海灘為主要建議點）。
